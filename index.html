Glass UI
    v1.0 · CSS + vanilla JS

    Glass components for the web

    One stylesheet and one small script. Plain HTML elements are styled inside a g-root container, so every snippet below is ready to paste. Glass needs something to blur, so place components over a photo, gradient or colour field.

    glass-ui.css · 27 KBglass-ui.js · 14 KBNo dependencies

    Install

    Add both files, then use the g- classes. Wrap your app (or any region) in g-root so box-sizing and the font apply. Interactive pieces start on their own; after inserting markup later, call Glass.init(container).

    <link rel="stylesheet" href="glass-ui.css">
<script src="glass-ui.js" defer></script>

<body class="g-root g-scene g-scene--gradient">
  …your page…
</body>

    Buttons

    Five variants, three sizes, icon and block forms, plus toggle and removable small buttons. Ghost is an icon with no glass, the size of a field's clear cross: a small icon toggle with aria-pressed, or, with data-reveal, an action that fades in when its row is pointed at. Hover highlights (on a phone too: hold a button, slide off to cancel), press scales down with a spring release, disabled drops to 38%.

      Ruler
      A section index for a long scrolling box. Mark where each section starts with data-ruler="Name" and nothing else: a hairline with the name under it appears at the right edge, as tall as the section's share of the scroll. The section in view is lit; a click jumps to it. It floats over the box, so give the box padding-inline-end if the content must stay clear of it.

      Для чтения
      
        
      Как выбрать фон для стеклянного интерфейса
      
        
      Стекло работает, когда под ним есть что размывать. Берите фон с плавными переходами тона и без мелких деталей: размытие превратит его в мягкое свечение.
      
        
      Для длинного текста держите строку около 65 символов и межстрочный интервал 1,6. Белый текст на стекле читается лучше всего, когда фон под ним тёмный.
